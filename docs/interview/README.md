## Dual-edition demo

In the running app header, switch **Edition**:

- **Baseline**: pre-Northline ask surface (no waiting-on-me, no show filters, no duplicate gate)
- **Northline pilot**: implemented slice (queue, filters, duplicate acknowledge)

Same codebase, same ledger spine. Toggle mid-demo for side-by-side comparison.
